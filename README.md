# Basic Network Sniffer — CodeAlpha Internship Task 1

A Python-based network packet sniffer built using Scapy.

## Features
- Captures live network traffic
- Displays Source/Destination IPs and Ports
- Identifies TCP, UDP, ICMP protocols
- Shows packet payload preview

## Setup
pip install -r requirements.txt

## Run (as Admin/sudo)
python sniffer.py

## Tools Used
- Python 3.x
- Scapy library
